# Web Search

For current events, documentation, or any time-sensitive fact: search the web instead of relying on training data. Cite the URL when results inform an answer.

- Brave: news, plain facts, prices/availability
- Exa: technical docs, "how X works", semantic/niche queries; also use it to fetch full page content when reading a page
- Budget: Brave free tier is ~2k queries/month — prefer few well-formed queries over many similar ones
